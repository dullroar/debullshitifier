# Clarity without truth claims

**Decision.** The prompt asks a language model to identify vague, inflated, evasive, or unsupported language while preserving the underlying claim where possible. It is intentionally opinionated about clarity, but it does not claim to establish truth. A polished answer is not treated as evidence.

**Contradicted by.** Wording that implies the prompt verifies facts or that cleaner prose makes a claim true.
